## 关卡扩容（72 关 + 最终任务）
- [x] 恰好 12 条支线 × 每条 6 关 = 72 关，另有 1 关最终任务

- [x] 难度指标（机制密度 + 坡度）随全局进度逐关单调递增
- [x] 72 关全部通关后「最终任务」才可用，此前为锁定提示

## 关卡变体（穿插好玩内容）
- [x] 6 种变体 `normal / sprint / gauntlet / airtime / fuelrun / downhill` 在全游戏中均至少出现一次
- [x] 每条支线第 3、5 关为特殊变体，其余为常规关
- [x] `airtime` 关未达标不判通过，并提示差距；达标后正常结算
- [x] `fuelrun` 关全场仅 1 个油罐，且经自动试跑验证可通过
- [x] `gauntlet` 关障碍呈通道式密集布局；`downhill` 关危险段密集
- [x] HUD 正确显示当前变体名称与 `airtime` 目标进度

## 机制性难度
- [x] 障碍物：撞上必摔车；腾空越过不摔车；不生成在出生点/终点缓冲区
- [x] 危险段：超阈值车速进入必摔车，低于阈值可安全通过，且有可提前预判的视觉提示
- [x] 限时门：每关 3~5 道；按时通过可正常结算；任一门超时则本局判负且**不写入星级与解锁**
- [x] 摔车惩罚：每次摔车扣 8% 燃料 + 2 秒计时惩罚，且惩罚计入三星判定用时
- [x] **反向验收**：至少后 1/3 关卡无法被"全程按油门"通关，且前 1/3 关卡仍保留全油门通关余量

- [x] 最终任务可通过（经自动试跑验证）
