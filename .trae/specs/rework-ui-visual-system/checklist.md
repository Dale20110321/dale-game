# Checklist（第 2 期：UI 视觉体系重构）

## 设计令牌
- [ ] `styles/tokens.css` 与 `src/config/ui-tokens.js` 逐键等价（键集合与取值完全一致）
- [ ] 令牌覆盖：表面层级、玻璃层、强调色、语义色 4 档、文本 3 档、排版阶梯、间距阶梯、圆角阶梯、动效时长与缓动
- [ ] `styles/main.css` 不再出现脱离令牌的字面色值
- [ ] `index.html` 正确引入 `tokens.css`，且仍 ≤ 200 行、无 `<style>` 块、无内联 `onclick`

## 组件库
- [ ] 存在 `glass-sheet / card / chip / btn(primary|ghost|danger)(sm|lg) / progress / stat / tabs / badge / empty` 全部组件
- [ ] 每个组件具备悬停、按下、键盘焦点、禁用、锁定五种可区分状态
- [ ] `src/ui/*.js` 中不存在用于配色的内联 `style`（布局类动态值如进度条宽度除外）
- [ ] `src/ui/components.js` 为纯函数渲染，返回非空 HTML 字符串

## 主菜单
- [ ] 菜单按"主玩法 / 养成与进度 / 支持"三组呈现，主玩法含 5 个入口（继续 / 闯关 / 最终任务 / 排位赛 / 无限模式）
- [ ] Hero 区显示状态摘要：车辆、金币、通关进度 x/72、总星、段位、无限最佳
- [ ] 摘要数值在结算后回到菜单立即更新，无需刷新页面
- [ ] 未解锁入口显示具体解锁条件与当前进度，点击不进入游戏
- [ ] 菜单背景为活体（场景渲染 + 渐晕 + 流动光斑），`prefers-reduced-motion` 下静止
- [ ] 键盘可完成按钮移动（方向键）与触发（Enter），Esc 关闭面板

## 面板体系
- [ ] 支线任务面板首屏只渲染 12 张支线卡片，不出现 72 关单层长列表
- [ ] 支线卡片含场景名、主题色描边、完成度 x/6 与总星
- [ ] 展开支线后展示 6 个关卡格（锁定 / 星级 / 变体图标 / 坡度 / 三星时限），并可返回卡片墙
- [ ] 车库、成就、升级车间、存档、排位赛、无限选图面板统一使用组件语言与令牌取色
- [ ] 所有锁定项给出明确解锁条件，无空面板、无死链、无 `undefined` / `[object Object]` 文本

## 游戏内 HUD
- [ ] 左上为分层玻璃卡片：关卡名 + 变体徽标 + 里程进度条 + 限时门倒计时
- [ ] 车速为仪表化呈现（数字 + 弧形量表 + 速度区间着色）
- [ ] 燃料为带刻度量表，低量时有脉冲提示
- [ ] 提示分四型 `info / success / warn / danger`，各有图标与色
- [ ] 危险段超速与限时门紧张警告为高优先级且不遮挡车身与前方赛道
- [ ] HUD 色值全部来自 `src/config/ui-tokens.js`，无裸色值
- [ ] 宽 < 520px 与横屏高 < 480px 时 HUD 元素互不重叠、不被裁切

## Canvas 渲染令牌化
- [ ] `src/render/**` 中白名单外的裸色值字面量为 0
- [ ] 12 个场景逐一渲染一帧均无异常，主题不发生错误串用
- [ ] 场景数据（`THEMES`）自身配色仍由数据驱动，未被并入令牌而造成场景失个性

## 画面后处理
- [ ] 存在渐晕与按场景的色彩分级，且使用复用型离屏画布、无逐帧对象分配
- [ ] 速度拖影随车速增强；远景淡化生效
- [ ] 接入 `THEMES[i].ambient` 生成天气覆盖层（雪 / 沙 / 雨 / 灰烬 / 雾 / 花粉）
- [ ] 画质档位 `高 / 中 / 低 / 关` 可用，低档关闭模糊类效果，设置被持久化
- [ ] 相同输入下"高"与"关"两档车身轨迹与用时完全一致（后处理不改变物理）
- [ ] `prefers-reduced-motion: reduce` 下拖影与光斑流动被关闭
- [ ] 菜单（非 play 状态）背景不因后处理出错或变黑

## 动效与反馈
- [ ] 面板有进出场过渡，切换面板不闪白
- [ ] Toast 分四型，同屏最多 2 条并排队，有进出场动画
- [ ] 结算结果卡含星级逐颗点亮、金币滚动计数、段位分变化，并提供"下一关 / 返回菜单"
- [ ] `prefers-reduced-motion: reduce` 下动效降级为无位移、仅透明度瞬变

## 可访问性与响应式
- [ ] 全部交互元素有 `:focus-visible` 焦点环
- [ ] 交互元素含 `aria-label` 或等价文本语义
- [ ] 正文级文本对比度 ≥ 4.5:1，大字号 ≥ 3:1
- [ ] 四档断点（≥1024 / 768~1023 / ≤767 / 横屏高<480）布局规则生效
- [ ] 触摸目标 ≥ 44×44px
- [ ] 纯键盘可完成：菜单 → 支线 → 选关 → 暂停 → 结算返回菜单
