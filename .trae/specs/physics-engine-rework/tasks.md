## 后续修复轮（同日）

按失败分类（`限时门超时 18` / `超时未通关 54`）逐个定位，实测轨迹给出三个真 bug：

1. **弹簧无阻尼回弹（主 bug）**：接触点只能推不能拉，所以弹簧**回弹**的能量在接触侧无处耗散
   → 整车持续弹跳。证据：诊断里"空中占比"**恒定 37–44%**、速度在 `0↔490` 之间震荡。
   修法：悬挂阻尼器在杆件**伸长**时把车架向下拉（内力，只作用于车架、不经接地点）。
   → 通过数 2/72 → **6/72**
2. **深穿透爆冲**：硬限位项在深穿透时算出天文数字的法向力（`pen=1426` → Fn≈276 万）
   → 整车被抛飞 → 落地倒立 → 摔车重生循环。
   修法：`Fn ≤ FN_MAX_K × mTot × g` + **限速的位置修正**（每子步 ≤2px，穿透 ≤ 容差；
   真掉出地图仍交给 `belowWorld → pitRewind` 兜底）
3. **抓地曾被误实现为速度阻尼器**：与驱动力对抗，稳态 `81·v = 540` → 车只能 7px/s 爬。
   修法：换成正确的动力链（Task 4）——扭矩 → 轮速 → 接触点相对滑动 → 库仑摩擦冲量 → 整车
