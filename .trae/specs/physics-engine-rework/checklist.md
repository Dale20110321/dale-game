- [ ] 被删常量/字段在全仓库（含测试与 README）不再出现

## 单侧接触与地形接口
- [ ] `terrain.js` 暴露解析接口：`groundY` / `groundSlope` / `groundNormal` / `groundCurvature`

- [ ] 断层（STEP_W）与陡坡处接触稳定：不爆冲、不穿透、不卡死

## 轮上动力学
- [ ] 两轮具有转动惯量与角速度状态，`wheelRear/wheelFront` 来自物理状态
- [ ] 动力链完整：油门 → 轮上扭矩 → 摩擦受限的切向力 → 推动整车
- [ ] 高抓地场景满油门直线加速时滑移率在阈值内（不打滑）
- [ ] 冰川/沼泽场景同油门滑移率显著更高、加速度更低（该打滑处打滑）
- [ ] 陡坡上法向力下降导致摩擦上限下降并出现打滑（注释所述行为成立）
- [ ] 刹车扭矩过大时出现锁死（轮角速度归零、转滑动摩擦）
- [ ] 滑移率作为状态量暴露给渲染层（本期只提供数据）
