## 怎么玩

| 按键 | 作用 |
|---|---|
| `→` / `D` | 踩油门 |
| `←` / `A` | 刹车 |
| `↓` / `S` | 倒车（先当刹车用，停稳后才挂上倒挡） |
| 空中 `←` / `→` | 调整车身姿态，决定落地是压平还是翻车 |

**没有跳跃键。** 想腾空只能靠冲上坡顶甩出去 —— 所以"什么时候松油门"比"按什么键"重要得多。

移动端直接触屏操作：屏幕左右下角是加速 / 刹车，倒车键在左侧偏上（全屏 🎮 按钮可随时开关这组虚拟键）。
桌面端还有 `R` 重开、`Esc` / `P` 暂停、`U` 升级车间、`M` 静音、`+` / `-` 缩放基准倍率。

> **镜头会随车速自动拉远。** 速度越高视野越广（最低缩到基准的 32%），
> 相机同时用速度前馈跟随，匀速行驶时稳态滞后为 0 —— 否则 350 km/h 下相机会
> 落后车 1458px、1000 km/h 下落后 4167px，也就是"地图跟不上"。
> `+` / `-` 调的是**基准**倍率，自动缩放叠在它上面。

## 游戏里有什么

**36 个场景 × 12 关 = 432 关**，外加一个最终任务。四种玩法：

| 玩法 | 内容 |
|---|---|
| **闯关** | 432 关主线，通关解锁下一关；三星分别对应"通关 / 吃满 70% 金币 / 跑进限时" |
| **比赛** | 三种赛制：**1V1 竞速**（单挑）、**多人竞技**（6 人同场，按名次发奖）、**团队接力**（3v3，比两队累计里程） |
| **排位赛** | 14 个段位（青铜 → 超越）× 3 星。1200 分开高级赛，3300 分登顶解锁无限模式自由选图，12000 分刷满全表 |
| **无限模式** | 无终点，随里程加难。**每次进入地形和场景都会重新摇** —— 不会每次打开都是同一条路。HUD 底部有「⏹ 结束本局」，随时能收手结算里程 |
| **宇宙联赛** | 9 联赛 × 3 分区（甲/乙/丙）× 3 场赛事。**分区按联赛段位分解锁，不按车** —— 买不起新车只是暂时跑不快，不会把玩法锁死。对手配速是该联赛的**固定值**，赛道长度 = 配速 × 时长，所以任何车跑任何一场都是 30~122 秒 |

每关的地形都是当场算出来的：先按难度挑一组地貌气质，再撒随机种子决定波长、相位、断层落点，最后实测一遍最大坡度、缩放到目标值。所以**同一关每次重玩的起伏细节都不一样，但难度是稳定的**。

### 27 辆车

**分 6 档**（普通 → 稀有 → 史诗 → 传说 → 神话 → **宇宙**）。
车库按档位分组、组内按车价从低到高排列。规则很简单：

- **越贵总体越强，但不是每一项都更强**。价格分的是档位，不是能力排名 ——
  一台便宜车完全可能在某一项上压过贵车（星轨的空中转场就比蜂鸟强）。
  想横向比较，看车库卡片里那格**满级真实可达极速**（金色底）：
  它是按物理解算出来的，与 HUD 表盘同源，贵的车换来的速度一眼可比。
- **贵的车升级更贵**。四项升满 = 基础 28,240 × 档位倍率（普通 1 → 稀有 5 → 史诗 12 → 传说 25 → 神话 40）。
- **贵的车形态更贵**，26 个形态的价格从 8,000 一路涨到 100 亿。
- **两台究极终局车**：
  - **奇点** —— 极速、抓地、油箱、扭矩四项全场第一，能开到 **350 km/h**（要开它的「绝对形态」）。
  - **归墟** —— 唯一一台能开到 **1000 km/h** 的车，而且**全程在天上飞**（开「终焉形态」）。
    它从不接触地面：没有悬挂、没有打滑、也摔不下来，代价是价格高到刷不出来。

### 七台宇宙级车 · 速度拖尾

七台宇宙级车（第一 ~ 第七宇宙速度）各自带**一条专属拖尾**，速度越快拖尾越强，
强到一定程度会进一步**蜕变成陨星 / 彗尾**。七台车**一台一种颜色、一种形态**：

| 车 | 形态 | 颜色 | 高速段 |
|---|---|---|---|
| 第一宇宙速度 | 电弧 | 冰蓝 | 三条分叉电弧 |
| 第二宇宙速度 | 螺旋 | 翡翠 | 两股反向螺旋束 |
| 第三宇宙速度 | 日冕 | 明黄 | 向后炸开的日珥 |
| 第四宇宙速度 | 余烬 | 烈橙 | 离散碎块，边飞边升 |
| 第五宇宙速度 | 涟漪 | 洋红 | 垂直于行进方向的激波环 |
| 第六宇宙速度 | 涡旋 | 星紫 | 一路收束的虫洞环 |
| 第七宇宙速度 | 光矛 | 星白 | 全场最长最直的一枚光矛 |

强度按**该车当前形态的极速**归一（九台车的标称极速跨 28,440 ~ 10,792,528,488 km/h，
**38 万倍**），所以每台车都能在自己 0~100% 的区间里走完整条曲线 —— 不开形态在地面跑
也有拖尾，开满形态就是一条横贯星空的彗尾。

九台按**真实的七级宇宙速度 + 光速**命名，各有各的颜色与拖尾画法：

| 车 | 极速 | 对应现实 |
|---|---|---|
| 🛰️ **星环** | 28,440 km/h | 第一宇宙速度（7.9 km/s，近地环绕速度） |
| 🚀 **离尘** | 40,320 km/h | 第二宇宙速度（11.2 km/s，地球逃逸速度） |
| 🌌 **越日** | 60,120 km/h | 第三宇宙速度（16.7 km/s，太阳系逃逸速度） |
| 🌠 **出银** | 1,890,000 km/h | 第四宇宙速度（525 km/s，银河系逃逸速度） |
| 🕸️ **破群** | 3,600,000 km/h | 第五宇宙速度（1000 km/s，本星系群逃逸速度） |
| 🕳️ **超脱** | 5,400,000 km/h | 第六宇宙速度（1500 km/s，超星系团逃逸速度） |
| 💫 **无界** | 6,300,000 km/h | 第七宇宙速度（1750 km/s，全域逃逸速度） |
| ⚡ **光锥** | 1,079,252,849 km/h | **光速 c** —— 形态满级恰好跑到光速本身 |
| 🌀 **弦外** | 10,792,528,488 km/h | **10 倍光速** —— 整个游戏的终点 |

起步送你一台免费试骑车「驮马」。它是**借来的**，刻意排在价格阶梯之外 ——
第一笔钱该拿去升级它，而不是换车。

除了这台借用车，每辆车都有一个专属形态：贴地锁死、极速过载、摔不坏、燃料无限、轨道炮、持续喷射……
八种形态在物理层各有一段实现。

**钱从哪来**：通关固定奖励 + 赛道上的金币 + 比赛名次奖金 + 排位赛奖金与升段奖励。
一轮 432 关全通约 213 万（通关固定奖励 69 万 + 赛道金币 143 万）；刷满一整条段位表另有 56.2 万。
光靠通关固定奖励的话，大约前 45 关能把一台入门车四项升满；搭上赛道金币会更早。
**宇宙级的车都不在这个预算里** —— 最便宜的「星环」车价 8 亿是全程收入的 194 倍，
最贵的「弦外」是 2.2 万倍。它们靠**宇宙联赛**的收入慢慢换，
联赛打满一轮的总奖金约 3.4×10^23，正好是「弦外」车价的一半多。

> 金币一律用**科学计数法**显示（`¥3.36×10^23`）—— 本作的金币跨度横跨 25 个数量级，
> 「万亿 / 亿亿」那套中文量词在 10^12 之后就只能写成没人读的串了。

## 本地跑起来

零依赖，**但需要一个静态服务器**（ES module 不能用 `file://` 直接打开）：

```bash
node tools/_serve.mjs      # 然后打开 http://localhost:8765
```

或者用任何你顺手的静态服务器：

```bash
python -m http.server 8765
npx serve .
```

### 想直接看所有车？

浏览器控制台执行这一行，刷新即可解锁全部车辆和 200 万金币：

```js
localStorage.setItem('bike_trial', '1'); location.reload()
```

删掉 `bike_trial` 这个键就恢复正常规则。

## 部署到 GitHub Pages

推上去之后进仓库 `Settings → Pages`，Source 选 `Deploy from a branch`，
分支 `main`、目录 `/ (root)`，保存即可。**不需要任何构建步骤。**

访问地址：https://dale20110321.github.io/dale-game/

> **想用干净的 URL（`/garage` 而不是 `/#garage`）？**
>
> GitHub Pages 是纯静态托管，没有服务端 rewrite，`/garage` 刷新会 404。
> 想做到"刷新后停在原页面"，只能用 **hash 路由**（`index.html#garage`）——
> 哈希不会发给服务器，所以它在 GitHub Pages 上一定可用。
>
> 好消息是游戏状态本来就存在 localStorage 里（当前关卡、当前车辆都存了），
> 所以刷新丢的只是"回到哪个面板"，进度不会丢。真要做的话，
> 加一个 `src/ui/router.js` 导出 `routeTo / currentRoute / startRouter`，
> 由 `main.js` 统一接线，不用动其它文件。

### 想生成一个可以双击游玩的单文件？

```bash
build.bat          # 需要 bun，产出 dist/game.bundle.js
```

日常开发不需要这一步 —— `index.html` 的主入口本来就是 `dist/game.bundle.js`，
`src/main.js` 只是打包产物缺失时的兜底。所以**每次改完源码都要重新跑一次**，
否则线上加载的还是旧代码。

## 想改点什么

```
src/
├── config/          ← 数据都在这，改数值不用碰逻辑
│   ├── constants.js    所有物理常量 + 升级/金币/段位表/赛制的唯一出处
│   ├── vehicles.js     26 辆车的数据
│   ├── levels.js       432 关的生成规则 + 地貌体格
│   └── themes.js       36 套场景主题
├── physics/         物理内核：刚体、接触、悬挂、动力链
├── render/          Canvas 绘制
├── ui/              菜单、车库、升级车间、结算等界面
├── game/            关卡流程、比赛、结算、进度
├── core/            存档、输入、工具
└── docs/            存档格式弃用说明（改存档前必读）
```

**三条最容易踩的规矩：**

1. **物理量只能在 `config/constants.js` 里换算。**
   别处写 `* 6` 这类魔法数，标度一旦分裂，HUD 显示的和实际跑的对不上，排查起来非常痛苦。

2. **`render/` 不许 import `game/`。**
   依赖是单向的：config ← physics ← game ← render/ui。反向 import 会把渲染和游戏逻辑绑死，
   以后想单独复用渲染层就做不到了。确实要共用的纯函数，往 `config/` 放。

3. **加车只要在 `vehicles.js` 里加一条，然后挂一个 `ultra.mode`。**
   八种形态（`stable` / `surge` / `shield` / `phase` / `railgun` / `warp` / `absolut` / `omega`）
   在物理层各有一段实现，新车**不需要改任何 `if`**。

4. **形态的"极速"必须是前馈 + 反馈，不能只有比例项。**
   `push = (V − v)·G` 在 `v → V` 时趋零，而 `V` 处的风阻却是有限正值，
   于是平衡点必然落在 `V` 之前 —— 标称 350 km/h 实测只到 285。
   正确写法是补一个恒等于**目标速度处风阻**的前馈项，使 `V` 本身成为稳定平衡点。
   两条终局形态（`absolut` / `omega`）都按这个口径标定，见 `constants.js`。

### 改数值之前先知道这几件事

`vehicles.js` 里有几条看起来莫名其妙的限制（`mass` / `inertia` 必须全表两两不同、
`airRot × inertia` 必须约等于 1），都是被物理逼出来的，改之前先看那里的注释。
注意 `grip` **没有**硬上限 —— 真正的约束是"满级 μ 仍要留出打滑空间"，
早期那条 `grp ≤ 2.2` 是写在 1.9 那代数据上的，早已不成立。

**改地形难度前先读 `levels.js` 的文件头注释。** 坡度不是直接给的，
而是"生成 → 实测 → 反解缩放系数"得到的，绕过这一步直接改振幅会让难度曲线断掉。

**改完 `phys` 要回头看一眼车价档位**，别让"更贵的车反而更弱"或"更便宜的车全面碾压"。
同理，**段位名不要和车名重名** —— 玩家分不清「奇点」是段位还是车。
