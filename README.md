## 怎么玩

| 按键 | 作用 |
|---|---|
| `→` / `D` | 踩油门 |
| `←` / `A` | 刹车 |
| `↓` / `S` | 倒车（先当刹车用，停稳后才挂上倒挡） |
| 空中 `←` / `→` | 调整车身姿态，决定落地是压平还是翻车 |

**没有跳跃键。** 想腾空只能靠冲上坡顶甩出去 —— 所以"什么时候松油门"比"按什么键"重要得多。

移动端直接触屏操作：屏幕左右下角是加速 / 刹车，倒车键在左侧偏上（全屏 🎮 按钮可随时开关这组虚拟键）。
桌面端还有 `R` 重开、`Esc` / `P` 暂停、`U` 升级车间、`M` 静音、`+` / `-` 缩放基准倍率。

> **镜头会随车速自动拉远。** 速度越高视野越广（最低缩到基准的 32%），
> 相机同时用速度前馈跟随，匀速行驶时稳态滞后为 0 —— 否则 350 km/h 下相机会
> 落后车 1458px、1000 km/h 下落后 4167px，也就是"地图跟不上"。
> `+` / `-` 调的是**基准**倍率，自动缩放叠在它上面。

## 游戏里有什么

**36 个场景 × 12 关 = 432 关**，外加一个最终任务、五种玩法、27 辆车、25 项成就：

| 玩法 | 内容 |
|---|---|
| **闯关** | 432 关主线，通关解锁下一关；三星分别对应"通关 / 吃满 70% 金币 / 跑进限时" |
| **比赛** | **3 种赛制 × 2 个档位**。赛制：1V1 竞速 / 多人竞技（6 人）/ 团队接力（3v3）。档位：普通（只发名次奖金）/ 排位（算段位分）。14 个段位青铜→超越，1200 分开高级排位，3300 分登顶解锁无限模式自由选图 |
| **无限模式** | 无终点，随里程加难。**每次进入地形和场景都会重新摇** —— 不会每次打开都是同一条路。HUD 底部有「⏹ 结束本局」，随时能收手结算里程 |
| **宇宙联赛** | 12 联赛 × 3 分区（甲/乙/丙）× 3 场赛事。**分区按联赛段位分解锁，不按车** —— 买不起新车只是暂时跑不快，不会把玩法锁死。对手配速是该联赛的**固定值**，赛道长度 = 配速 × 时长，所以任何车跑任何一场都是 30~122 秒 |

每关的地形都是当场算出来的：先按难度挑一组地貌气质，再撒随机种子决定波长、相位、断层落点，最后实测一遍最大坡度、缩放到目标值。所以**同一关每次重玩的起伏细节都不一样，但难度是稳定的**。

### 27 辆车

**分 6 档**（普通 → 稀有 → 史诗 → 传说 → 神话 → **宇宙**）。
车库按档位分组、组内按车价从低到高排列。规则很简单：

- **越贵总体越强，但不是每一项都更强**。价格分的是档位，不是能力排名 ——
  一台便宜车完全可能在某一项上压过贵车（驮马的空中转体就比大多数贵车强）。
  想横向比较，看车库卡片里那格**满级真实可达极速**（金色底）：
  它是按物理解算出来的，与 HUD 表盘同源，贵的车换来的速度一眼可比。
- **贵的车升级更贵**。四项升满 = 基础 28,240 × 档位倍率（普通 1 → 稀有 5 → 史诗 12 → 传说 25 → 神话 40）。
- **贵的车形态更贵**，形态价格从 6,000 一路涨到 4.3×10^33。
- **奇点**（¥120,000）是地面车的天花板：极速、抓地、油箱、扭矩四项全场第一，
  开「绝对形态」能到 350 km/h。再往上就只能靠下面那十二台宇宙级车了。

### 十二台宇宙级车 · 速度拖尾

按**真实的七级宇宙速度，加上 1 / 10 / 100 / 1000 / 10000 倍光速**命名。每一台带一条专属拖尾，速度越快拖尾越强，
强到一定程度会进一步蜕变成陨星与彗尾：

| 车 | 形态极速 | 对应现实 | 拖尾 |
|---|---|---|---|
| 🛰️ **星环** | 28,440 km/h | 第一宇宙速度（7.9 km/s，近地环绕速度） | 三条分叉电弧，冰蓝 |
| 🚀 **离尘** | 40,320 km/h | 第二宇宙速度（11.2 km/s，地球逃逸速度） | 两股反向螺旋束，翡翠 |
| 🌌 **越日** | 60,120 km/h | 第三宇宙速度（16.7 km/s，太阳系逃逸速度） | 向后炸开的日珥，明黄 |
| 🌠 **出银** | 1,890,000 km/h | 第四宇宙速度（525 km/s，银河系逃逸速度） | 离散碎块，边飞边升，烈橙 |
| 🕸️ **破群** | 3,600,000 km/h | 第五宇宙速度（1000 km/s，本星系群逃逸速度） | 垂直于行进方向的激波环，洋红 |
| 🕳️ **超脱** | 5,400,000 km/h | 第六宇宙速度（1500 km/s，超星系团逃逸速度） | 一路收束的虫洞环，星紫 |
| 💫 **无界** | 6,300,000 km/h | 第七宇宙速度（1750 km/s，全域逃逸速度） | 全场最直的一枚光矛，星白 |
| ⚡ **光锥** | 1,079,252,849 km/h | **光速 c**，形态满级恰好跑到光速本身 | 向后收束的锥面，纯白 |
| 🌀 **弦外** | 10,792,528,488 km/h | **10 倍光速** | 两道剪切的断裂面，品红 |
| ♾️ **裂界** | 107,925,284,880 km/h | **100 倍光速** | 向车尾透视收缩的光网，酸绿 |
| 🌠 **千界** | 1,079,252,848,800 km/h | **1000 倍光速** | 四股互相缠绕的编结，霓粉 |
| 💠 **无极** | 10,792,528,488,000 km/h | **10000 倍光速** —— 整个游戏的终点 | 向内塌缩的事件视界，极深紫 |

拖尾强度按**该车此刻的极速**归一（标称极速横跨 **38 亿倍**），
所以每台车都能在自己 0→100% 的区间里走完整条曲线：不带形态在地面跑也有拖尾，
开满形态就是一条横贯星空的彗尾。

### 宇宙联赛

十二个联赛，每个联赛三个分区（对手配速分别是参考配速的 60% / 74% / 86%），
每个分区三场赛事（短距冲刺 / 群雄竞速 / 长程接力），一共 108 场。

**分区按联赛段位分逐个解锁，不按车解锁** —— 按车解锁会让"买了新车"直接等于
"解锁了新内容"，那是在卖车不是在分层。买不起新车只是暂时跑不快，不会把整块玩法
锁死在门外。

对手配速是该联赛的**固定值**，不跟着你的车速变；赛道长度 = 配速 × 分区时长，
所以任何车跑任何一场都是 30~122 秒。面板上会直接标出「你的极速够不够」。

起步送你一台免费试骑车「驮马」，刻意排在价格阶梯之外 —— 第一笔钱该拿去升级它，
而不是换车。除了这台，每辆车都有一个专属形态：贴地锁死、极速过载、摔不坏、
燃料无限、轨道炮、持续喷射……八种形态在物理层各有一段实现。

**钱从哪来**：通关固定奖励 + 赛道金币 + 比赛名次奖金 + 排位段位奖励。
一轮 432 关全通约 213 万，大约够把一台入门车四项升满。

宇宙级的车都不在这个预算里 —— 最便宜的「星环」车价 8 亿是全程收入的 194 倍，
最贵的「无极」是 **1600 万倍**。它们靠**宇宙联赛**慢慢换：每个联赛的基准奖金
大致是该联赛旗舰车车价的 70%（L9 弦外层 3.36×10^23 对 4.72×10^23，
L12 无极层 2.45×10^32 对 3.44×10^32），所以在对应联赛打到高分区，
一场就够把车买下来。

> 金币一律用科学计数法显示（`¥3.36×10^23`）。本作的金币跨度横跨 30 个数量级，
> 「万亿 / 亿亿」那套中文量词在 10^12 之后就只能写成没人读的串了。

### 25 项成就

分四段：**入门**（随手就拿到）/ **熟练**（要真打一会儿）/ **精通**（玩到中后期）/
**超越**（光速梯队 + 光年里程，只有宇宙级车碰得到）。

后两段是给长线的：每跨过一档光速（c → 10c → 100c → 1000c → 10000c）点亮一个速度成就，
「光年之旅 / 深空行者」要的是**一光年 = 9.46×10^15 米** —— 在光速车上几分钟，
在普通车上基本不可能，所以它天然属于终局玩家。

## 本地跑起来

零依赖，**没有构建步骤**，但需要一个静态服务器（ES module 不能用 `file://` 直接打开）。
用任何你顺手的静态服务器都行：

```bash
python -m http.server 8765
npx serve .
```

然后打开 http://localhost:8765。

## 部署到 GitHub Pages

推到 `main` 分支后，进仓库 `Settings → Pages`，Source 选 `Deploy from a branch`、
分支 `main`、目录 `/ (root)`，保存即可。**不需要任何构建步骤**。

在线试玩：https://dale20110321.github.io/dale-game/

仓库里**没有任何打包产物** —— `index.html` 直接以
`<script type="module" src="./src/main.js">` 加载源码，所以改完源码刷新就是新的，
不存在"忘了重新打包、线上还在跑旧代码"这种坑。

## 想改点什么

```
src/
├── config/          ← 数据都在这，改数值不用碰逻辑
│   ├── constants.js    所有物理常量 + 升级/金币/段位表/赛制的唯一出处
│   ├── vehicles.js     27 辆车的数据
│   ├── levels.js       432 关的生成规则 + 地貌体格
│   └── themes.js       36 套场景主题
├── physics/         物理内核：刚体、接触、悬挂、动力链
├── render/          Canvas 绘制
├── ui/              菜单、车库、升级车间、结算等界面
├── game/            关卡流程、比赛、结算、进度
└── core/            存档、输入、工具
```

`index.html` 直接以 `<script type="module" src="./src/main.js">` 加载源码 ——
仓库里没有任何打包产物，改完刷新就是新的。

**三条最容易踩的规矩：**

1. **物理量只能在 `config/constants.js` 里换算。**
   别处写 `* 6` 这类魔法数，标度一旦分裂，HUD 显示的和实际跑的对不上，排查起来非常痛苦。

2. **`render/` 不许 import `game/`。**
   依赖是单向的：config ← physics ← game ← render/ui。反向 import 会把渲染和游戏逻辑绑死，
   以后想单独复用渲染层就做不到了。确实要共用的纯函数，往 `config/` 放。

3. **加车只要在 `vehicles.js` 里加一条，然后挂一个 `ultra.mode`。**
   八种形态（`stable` / `surge` / `shield` / `phase` / `railgun` / `warp` / `absolut` / `omega`）
   在物理层各有一段实现，新车**不需要改任何 `if`**。

4. **形态的"极速"必须是前馈 + 反馈，不能只有比例项。**
   `push = (V − v)·G` 在 `v → V` 时趋零，而 `V` 处的风阻却是有限正值，
   于是平衡点必然落在 `V` 之前 —— 标称 350 km/h 实测只到 285。
   正确写法是补一个恒等于**目标速度处风阻**的前馈项，使 `V` 本身成为稳定平衡点。
   两条终局形态（`absolut` / `omega`）都按这个口径标定，见 `constants.js`。

### 改数值之前先知道这几件事

`vehicles.js` 里有几条看起来莫名其妙的限制（`mass` / `inertia` 必须全表两两不同、
`airRot × inertia` 必须约等于 1），都是被物理逼出来的，改之前先看那里的注释。
注意 `grip` **没有**硬上限 —— 真正的约束是"满级 μ 仍要留出打滑空间"，
早期那条 `grp ≤ 2.2` 是写在 1.9 那代数据上的，早已不成立。

**改地形难度前先读 `levels.js` 的文件头注释。** 坡度不是直接给的，
而是"生成 → 实测 → 反解缩放系数"得到的，绕过这一步直接改振幅会让难度曲线断掉。

**改完 `phys` 要回头看一眼车价档位**，别让"更贵的车反而更弱"或"更便宜的车全面碾压"。
同理，**段位名不要和车名重名** —— 玩家分不清「奇点」是段位还是车。
