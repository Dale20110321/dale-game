## 表盘真实性（本阶段新增的验收口径）

> 用户反馈「很多车根本跑不到满速」。实测全 32 台车 × 满级 × 45 秒，
> 达成率只有 52%~70%、形态车低到 18%。定位出**三处**表盘与实车各算各的地方，
> 全部修复。

- [x] `topSpeedOf` 的 loss 与 `applyDrag` **逐项对齐**：`k·v² + LINEAR_DRAG_K·v + roll`
      （漏掉线性阻力项时全表虚高近一倍 —— v=1000 px/s 时它独占 46% 的阻力）
- [x] `topSpeedOf` 接受形态覆写参数（`mu` / `airDragK` / `wheelieMul` / `rpmK`），
      loss 不再恒用全局 `AIR_DRAG_K`
- [x] 形态表盘不再由 `topSpeed *= fx.speedN` 人写死，改为 `retuneTopSpeed()` 用实车参数重算；
      形态提速主力是**降风阻**（不增加驱动力、不带来翻车），翘头限幅只做保守的 1.8 倍放宽
- [x] 全 32 台车 × 满级 × 45 秒达成率：普通车 **76%~95%**，达成率 <85% 的组数 56 → **11**（共 64 组）
- [x] 相机前推 / 倒挡基准 / 危险段限速与表盘读同一个值，指针走不满就是真的跑不到
- [x] **无限模式下 6 台宇宙级车形态极速全部达到标称**（finishX=∞，25 秒实测）
      归墟 1000 / 星殒 5000 / 坍缩 10000 / 虚掷 25000 / 终末 50000 / 无相 **100,475** km/h
- [x] **相机缩放下限随速度放开**（"看起来跑不出来"的直接原因）
      固定下限 0.32 把视野锁在 ±1km，而 10 万 km/h 一帧走 46,296px = 461 米 ——
      车不是"飞快"，而是每帧闪出画面，玩家只看到空地。
      现在缩放取 `min(base·k, 可见性上限)`：低速维持原观感与 CAM_ZOOM_MIN，
      高速自动让位（无相 0.0065，可见半宽 74km）。实测 60 秒 3480 帧**零帧出画**。
