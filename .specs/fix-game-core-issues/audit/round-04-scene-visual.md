## 🔴 整层失效级 BUG

### VIS-1 `src/render/*.js` 对 8 种形态**零引用** —— 形态的视觉表现完全不存在

`activeMode` / `ultraFlags` / `isFlighter` / `isAbsolut` / `isCrashImmune` / `isUltraStable` 在整个 render 层（13 个文件）**零引用**（逐文件 grep 确认）。

stable / surge / shield / phase / railgun / warp / absolut / omega 开启后，**车体与骑手像素级完全不变**。玩家花 ¥681000（终焉·湮灭领域）后画面无变化，无法确认是否生效。形态开启/结束也**零过渡**（`panels.js:1194` 只写 `store.ultra[v.id]=true`，无任何插值状态）。

**修法**：在 `drawBike` 里读 `activeMode()`，至少给 shield 画护盾泡、stable 画磁吸地效、omega/absolut 画能量环；加 `store.ultraBlend` 0→1 缓动；形态切换走 0.3s 过渡。

### VIS-2 12 台宇宙车的拖尾，9 台在正常游玩中**一次都不会出现**

- `scene.js:41-49`：巡航分支 `return` 在 `drawTrail`（第 69 行）**之前** → 巡航层不画拖尾。而 `cruise.js:14` 的注释明确宣称"拖尾照旧"。
- `trail.js:74-81`：归一分母用 `topSpeed`，`k>0` 需 `v > 0.14×topSpeed`；但 omega 形态下 `topSpeed` 被直接赋成 cruise（`bike.js:615`），cv4–cv12 的 `TRAIL_ON×topSpeed` 比巡航门槛**高 2~7 个数量级** → k 恒为 0。

实测枚举：cv1/2/3 有可见窗口但 max k 仅 0.63/0.44/0.23（陨星层需 k≥0.50，**只有 cv1 能到 0.35**）；**cv4–cv12（含全部光速级与无极）签名拖尾永不出现**。而形态满级从离尘起就进巡航层 = 永远看不到。

### VIS-3 `terrain.js:312` 巡航色带的采样缩放方向写反 —— 画的是**玩家已驶过的地面**

`x0` 是屏幕 px，采样却写成 `cx + x0*z`（应为 `/z`）：
- zoom 0.32 时可见 6000px 世界宽，**只采样 614px（10.2%）**；zoom 0.05 时只剩 **0.25%**。
- 更糟：采样区间 `[cam.x, cam.x+614]` **完全落在车左侧**（车停在屏幕 38% = 2280 世界 px）→ 3600 km/h 时画出来的"地面"是玩家已经驶过的地面。

**修法**：改成 `x0/z` 与 `bandW/z*f`。这一条同时解释了为什么"高速下不能预判地形"。

### 地形绘制
